# TBarba Portfolio

Professional portfolio site for **TBarba** — Video Editor & Motion Designer.

## Structure
- `index.html` — Main portfolio page
- `style.css` — Cinematic dark theme styles
- `script.js` — Config-driven rendering engine
- `portfolio.json` — All site content (edit this to update the portfolio)

## Editing
Update `portfolio.json` to change:
- Site name, title, tagline, bio, email, social links
- Demo reel video and poster
- Projects (title, category, thumbnail, video URL, description)

## Categories
Projects are filtered by: Videos, Shorts, 3D, Motion Graphics

## Live Preview
The portfolio is served at `/portfolio/index.html` within the Base44 app.
